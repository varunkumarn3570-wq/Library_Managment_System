# Library Management System

A SQL-based Library Management System project developed using MySQL and MySQL Workbench.

## Project Overview

This project is designed to manage library operations such as:

- Book management
- Member management
- Book issue and return tracking
- Employee records
- Library database handling

The project demonstrates database design and SQL query skills using relational database concepts.

---

## Features

- Create and manage library tables
- Add, update, and delete records
- Track issued and returned books
- Manage member details
- Use relational database concepts
- Perform SQL queries for data retrieval

---
